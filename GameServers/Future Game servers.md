# Possible, Future, and In-Development Servers

## Jabroni Brawl: Episode 3

- Store: https://store.steampowered.com/app/869480/Jabroni_Brawl_Episode_3/
- Repository: https://github.com/LacledesLAN/gamesvr-jabronibrawl3

Jabroni Brawl: Episode 3 is a massive collection of game modes, maps, and weapons, built by an enormous group of modders using the magic of the Source engine. First started in 2012, JB3 expands upon what made the Half-Life mod scene great by combining ideas and concepts from various Half-Life 1 and 2 mods, such as Rocket Crowbar, Scientist Hunt, Jaykin Bacon, and many more. In addition, this game seeks to pay tribute to Valve's vast library of games, as players will be treated to an assortment of maps and player models taken from or inspired by various Valve games. We've also thrown in our own original ideas, with the end result being a silly but fun online deathmatch experience.

### Current Status

There is currently a working Docker image, but configuration has become challenging and we do not fully understand the game modes and maps. The current goal is to figure out how to launch the server and be able to select any game type or mode with the right maps.

## Counter-Strike 2

- Store: https://store.steampowered.com/app/730/CounterStrike_2/

For over two decades, Counter-Strike has offered an elite competitive experience, one shaped by millions of players from across the globe. And now the next chapter in the CS story is about to begin. This is Counter-Strike 2.

A free upgrade to CS:GO, Counter-Strike 2 marks the largest technical leap in Counter-Strike's history. Built on the Source 2 engine, Counter-Strike 2 is modernized with realistic physically-based rendering, state-of-the-art networking, and upgraded Community Workshop tools.

### Current Status

The "Elephant in Bean's LL server laboratory that is never mentioned" has remained largely unaddressed. Since the launch of CS2, LL events have shifted to more casual events where tournaments are not run. There has been no development or attempts to dockerize it since. This would also be the first Source 2 engine server.

## Midnight Guns

- Store: https://store.steampowered.com/app/1877600/Midnight_Guns/


The developers describe the content like this: it depicts blood drips and sprays, as well as immolation. All violence depicted is not particularly graphic, and little to no gore is shown.

### Current Status

This is still in the early stages. As of summer 2026, this in-development free mod/game is based on Quake 2 and is a reimagining of the boomer-shooting chaos of Action Quake. There is no current Steam release date, and downloading the server files currently requires a login to a Steam account that has an early copy.
